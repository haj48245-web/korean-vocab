# 한걸음 · 韩语单词

一个**纯网页版**的韩语背单词工具，照着「百词斩」的节奏做的：看韩语单词 → 四选一 → 立刻看意思、用法和语法 → 答错的词稍后再考一遍 → 按遗忘曲线隔几天再考。

为 iPhone Safari 优化（也支持安卓/电脑浏览器），可「添加到主屏幕」，像 App 一样全屏使用，进度存在手机本地。

![首页](tools/shots/home.png)

## 功能

- **4205 词分级词库**：TOPIK 1–6 级共 4205 词（1 级 882 / 2 级 876 / 3 级 658 / 4 级 555 / 5 级 794 / 6 级 440），可按级别多选，每级显示进度。
- **四选一**：显示韩语单词，四个中文释义选项，干扰项优先取同级别、同词性的词。
- **即时反馈**：无论答对答错，都会展开「中文意思 + 图形记忆 + 发音 + 发音规则 + 构词/用法 + 例句 + 语法点」。
- **图形记忆**：每个词配一个图形符号（emoji）当记忆钩子，例如 사과 🍎、지하철 🚇、화가 나다 😠；离线可用，不依赖图片服务器。
- **发音**：点喇叭即播韩语语音；单词走在线 TTS（约 0.7 秒出声，卡片出现时已预加载），**644 个例句语音已提前生成并打包**（`audio/sentences.bin`，2.5 MB），点例句喇叭直接从本地切片播放，秒响且可离线。同时标注韩国标准发音（발음），例如 학생 → 학쌩。
- **发音规则**：13 条常用读音变化（连音、紧音化、鼻音化、流音化、ㅎ 脱落/送气、腭化、平音化…），卡片上直接标出用了哪条，点开有说明和例子；也能在「我的 → 发音规则」里查全表。
- **构词**：2440+ 个汉字词标出对应汉字（例如 고등학생 → 高等學生），中国人背韩语单词的捷径。
- **错词重考**：答错的词会插入到本次队列后面，过几张卡再考一次；同时把复习时间排到明天。
- **遗忘曲线**：每个词按 `1 → 3 → 7 → 15 → 30 → 60 → 120` 天的间隔重现；答对升一级，答错回到 1 天。答错的词还会进「错词本」。
- **每日目标**：10 / 15 / 20 / 30 / 50 / 100 个新词可随时切换；复习量不占每日目标。
- **语法库**：42 个韩国人日常真正在用的语法点（初/中/高），含接续形式、说明、例句和易错提示；单词卡里的语法标签可点开对应详解。
- **词典**：4205 词全表可浏览，支持韩语/中文搜索、按级别筛选，以及「全部 / 今天学的 / 未学 / 错词」四种状态筛选；点任意词看释义、发音、构词、例句和复习状态。
- **今天学了什么**：「我的」页顶部直接列出今天学过的词（带发音），点「在词典里查看」可按「今天学的」筛选全部。
- **学习统计**：累计词数、已掌握、正确率、连续天数、最近 7 天柱状图、未来 7 天复习计划。
- **数据自保**：进度只存在本机浏览器，可「导出备份」为 JSON；换手机或清缓存前建议先导出。
- **离线可用**：部署在 https 上时注册 Service Worker，第二次打开即使断网也能背（发音除外）。

## 在 iPhone 上使用

### 方式一：电脑开热点/同一 Wi-Fi（最快）

1. 电脑上双击 `start-server.bat`（需要 Node.js；也可以直接运行 `node tools/serve.js 8090`）。
2. 查看电脑的局域网 IP（Windows：`ipconfig`，找 WLAN 的 IPv4，例如 `172.20.10.8`）。
3. 手机连同一个 Wi-Fi，用 Safari 打开 `http://172.20.10.8:8090`。
4. 点 Safari 底部分享按钮 →「添加到主屏幕」，之后从桌面图标进入即可全屏使用。

> 如果打不开，多半是 Windows 防火墙拦了：右键 `allow-firewall.bat` →「以管理员身份运行」，放行 8090 端口。

### 方式二：部署到静态网站（推荐长期使用）

把整个文件夹上传到任意静态托管（GitHub Pages、Netlify Drop、Vercel、Cloudflare Pages 都行），得到一个 https 网址，手机打开即可。无需后端、无需数据库。

例如 GitHub Pages：新建仓库 → 上传这些文件 → Settings → Pages → 选择分支根目录 → 得到 `https://用户名.github.io/仓库名/`。

## 数据结构（想加词很方便）

### 精讲词库：`js/words-N.js`

每个词一行，用 `|` 分隔：

```
单词|中文释义|词性|TOPIK级别|例句|例句翻译|用法|语法
```

- 语法写成 `关键字@说明`，关键字与 `js/grammar.js` 里的 `key` 对应时会显示「详解」按钮，例如 `을/를@宾格助词`。
- 没有用法或语法就留空，但**不要删除中间的竖线**。
- 想补充用法，也可以写在 `js/notes.js` 里，格式 `单词|用法说明`。

### 扩展词库：`js/words-extra.js`

由 `tools/build_db.py` 从原始数据生成，格式是紧凑数组：

```js
addCompact([["경찰","警察","명사",1,"경ː찰","警察"], ...])
//          韩语   中文   词性 级别 发音   构词
```

词性用韩语：`명사 / 동사 / 형용사 / 부사 / 대명사 / 수사 / 감탄사 / 관형사 / 표현`。

改完后刷新页面即可，不需要构建。

## 发音

- 播放走在线韩语语音接口（有道词典的 TTS），不需要安装语音包，安卓/iPhone 都能出声。
- **例句语音不走在线接口**：有道对超过 5 个音节的句子会直接 500，所以 644 个例句用 `tools/build_sentences.js` 批量生成，拼成 `audio/sentences.bin`，索引在 `js/sentences-index.js`；点例句时按字节切出对应片段播放，第一次会下载 2.5 MB，之后秒播且断网可听。
- 卡片出现时会静默预加载当前词的音频，点喇叭基本立刻响。
- 断网或接口失败时，自动退回 `speechSynthesis` 系统朗读（iPhone 需要在系统里装韩语语音）。
- 数据里另存了**韩国标准发音**（连音、紧音等），例如 국적 → 국쩍、좋아요 → 조아요，便于对照。
- 没有现成标注的词，用 `js/pron.js` 的发音引擎按规则推导，并在卡片上标出用到的规则；引擎与 1631 条人工标注比对，整词一致率约 84%（剩余差异多是「성격→성껵」这类汉字词特例紧音，不按一般规则走）。

## 复习算法

```
答对：阶段 +1，下次复习 = 今天 + [1,3,7,15,30,60,120][阶段-1] 天
答错：阶段 = 1，下次复习 = 明天
同一场次内重考答对：只记录对错，不重复加阶段
```

首页与「我的」页会显示未来 7 天的复习量。

## 开发与自检

```bash
python tools/build_db.py      # 从 tools/raw/*.json 重新生成扩展词库
node tools/validate.js        # 词库完整性：重复、缺字段、语法键匹配
node tools/pron-test.js       # 用人工标注检验发音引擎准确率
node tools/e2e.js http://127.0.0.1:8090   # 用真实浏览器跑完整答题流程
node tools/e2e2.js http://127.0.0.1:8090  # 复习调度与间隔
```

## 词表来源与许可

- **精讲 644 词**：按韩国国立国语院《国际通用韩国语标准教育课程》的级别思路整理，参考公开的 [TOPIK 词表](https://everykoreans.com/topik-vocabulary-list/)，例句、用法、语法解析为学习目的编写。
- **扩展 3561 词**：来自开源项目 **Open Yonsei Korean Vocabulary**（《延世韩国语》1–6 册词表，中韩英对照），按 [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/) 使用，级别按册数对应 1–6 级。
  - 项目地址：<https://github.com/Amulopapa67/open-yonsei-korean-vocabulary>
  - 署名：Open Yonsei Korean Vocabulary contributors, “Open Yonsei Korean Vocabulary dataset”, version 0.1.0, CC BY-SA 3.0.
  - 本项目对其做了筛选（去掉短语/语法条目、去重、补充发音与构词字段）与格式转换，数据本身仍遵循 CC BY-SA 3.0。
- 两份词表都属于**学习用整理词表，不是官方真题词表**；个别释义可能不完整，精讲词库优先用于入门。
